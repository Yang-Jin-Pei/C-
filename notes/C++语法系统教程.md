## 第 1 章　程序骨架

每个程序都长这样，先抄骨架再填代码：

```cpp
#include <iostream>   // 引入"输入输出"工具箱

int main() {          // 程序大门，从这里开始执行
    // 你的代码写在这里
    return 0;         // 正常结束
}
```

## 第 2 章　注释

注释是写给人看的，电脑会**跳过**它：

```cpp
// 这是单行注释

/*
   这是多行注释
   可以写很多行
*/
```

## 第 3 章　变量与数据类型

### 3.1 变量 = 有名字的盒子

```cpp
类型 名字;        // 声明：造一个盒子
名字 = 值;        // 赋值：往盒子里放东西
```

```cpp
int age;          // 造一个叫 age 的盒子，规格是"整数"
age = 25;         // 放进 25
int score = 90;   // 一步到位：声明 + 赋值
```

### 3.2 六种基本类型（先背这六个）

| 类型 | 装什么 | 例子 | 关键 |
|---|---|---|---|
| `int` | 整数 | `42`、`-7` | 最常用 |
| `double` | 小数 | `3.14`、`-0.5` | 带小数点就用它 |
| `char` | **一个**字符 | `'a'`、`'3'` | 用**单引号** |
| `bool` | 真/假 | `true`、`false` | 只有两个值 |
| `std::string` | 一串文字 | `"hello"` | 用**双引号**，需 `#include <string>` |
| `void` | 空（没有值） | — | 后面函数会用到 |

> ⚠️ `char` 用单引号 `'a'`，`string` 用双引号 `"hello"`，别混。

### 3.3 常量 const（值不能改）

```cpp
const double PI = 3.14159;   // 之后谁也别想改 PI
PI = 3.0;                    // ❌ 编译报错
```

### 3.4 命名规则

- 只能字母、数字、下划线 `_`，**不能以数字开头**；
- 取有意义的名字：`age` 比 `a` 好一万倍；
- 区分大小写：`age` 和 `Age` 是两个盒子。

## 第 4 章　运算符

### 4.1 算术运算

```cpp
int a = 7 + 2;    // 9   加
int b = 7 - 2;    // 5   减
int c = 7 * 2;    // 14  乘
int d = 7 / 2;    // 3   ⚠️整数除法，丢掉小数！
int e = 7 % 2;    // 1   取余数
```

> ⚠️ **第一大坑**：`7 / 2` 在 C++ 里等于 **3**，不是 3.5！因为两个 `int` 相除，结果还是 `int`，小数部分被扔掉。
> 想要 3.5，必须让一个是小数：`7.0 / 2` 或 `double(7) / 2`。

### 4.2 赋值运算

```cpp
int x = 10;
x += 5;    // x = 15   等价于 x = x + 5
x -= 3;    // x = 12
x *= 2;    // x = 24
x /= 4;    // x = 6
```

### 4.3 比较运算（结果是 bool：true/false）

| 符号 | 意思 | 符号 | 意思 |
|---|---|---|---|
| `==` | 等于 | `>` | 大于 |
| `!=` | 不等于 | `<` | 小于 |
| `>=` | 大于等于 | `<=` | 小于等于 |

> ⚠️ **第二大坑**：判断"相等"是 **`==`（两个等号）**。一个 `=` 是赋值，不是判断！
> `if (x == 5)` 是对的，`if (x = 5)` 是错的（它把 5 赋给 x，几乎永远为真）。

### 4.4 逻辑运算

| 符号 | 意思 | 说明 |
|---|---|---|
| `&&` | 与 | 两边都真才真 |
| `\|\|` | 或 | 一边真就真 |
| `!` | 非 | 取反 |

```cpp
bool ok = (age >= 18 && age <= 60);  // 18~60 之间
bool big = (x > 100 || x < -100);    // 绝对值超过 100
```

### 4.5 自增自减

```cpp
int i = 0;
i++;    // i = 1   自增（加 1）
i--;    // i = 0   自减（减 1）
```

## 第 5 章　输入输出

### 5.1 输出 cout（打印到屏幕）

```cpp
std::cout << "年龄是 " << age << " 岁" << std::endl;
```

- `std::cout`：输出工具
- `<<`：把右边"送进去"，可以**连续送**（串联多个）
- `std::endl`：换行

```cpp
std::cout << 42 << std::endl;        // 输出数字
std::cout << 3.14 << std::endl;      // 输出小数
std::cout << 'a' << std::endl;       // 输出字符
std::cout << "hi" << std::endl;      // 输出文字
```

### 5.2 输入 cin（从键盘读）

```cpp
int x;
std::cin >> x;          // 程序停下，等用户敲一个整数回车
```

### 5.3 一次读多个

```cpp
int a, b;
std::cin >> a >> b;     // 用户敲：3 5（空格或回车隔开）
```

## 第 6 章　条件语句

### 6.1 if（如果……就……）

```cpp
if (条件) {
    // 条件为 true 时执行
}
```

```cpp
int score = 85;
if (score >= 60) {
    std::cout << "及格" << std::endl;
}
```

### 6.2 if-else（否则）

```cpp
if (条件) {
    // 真
} else {
    // 假
}
```

### 6.3 if-else if-else（多分支）

```cpp
if (score >= 90) {
    std::cout << "A" << std::endl;
} else if (score >= 80) {
    std::cout << "B" << std::endl;
} else {
    std::cout << "C" << std::endl;
}
```

## 第 7 章　循环

### 7.1 for（最常用，重复固定次数）

```cpp
for (int i = 0; i < n; i++) {
    // 重复执行 n 次
}
```

三块拆开读：`int i = 0`（起点）→ `i < n`（还能继续吗）→ `i++`（每轮 +1）。

```cpp
// 打印 0 到 4
for (int i = 0; i < 5; i++) {
    std::cout << i << " ";
}
// 输出：0 1 2 3 4
```

### 7.2 while（条件为真就循环）

```cpp
while (条件) {
    // 条件为 true 就一直执行
}
```

### 7.3 break / continue

```cpp
break;      // 立刻跳出整个循环
continue;   // 跳过本轮，进入下一轮
```

## 第 8 章　数组（固定大小）

```cpp
int arr[5] = {3, 1, 4, 1, 5};   // 造一个能装 5 个 int 的数组
arr[0] = 10;                    // 改第一个元素
std::cout << arr[2];            // 输出 4
```

> ⚠️ **第三大坑**：下标从 **0** 开始。5 个元素的下标是 0、1、2、3、4，**没有 arr[5]**。

## 第 9 章　vector（动态数组，EDA 最常用）

数组大小要提前定死，很麻烦。`vector` 是"能自动伸缩的数组"：

```cpp
#include <vector>               // 要用 vector 必须加这行

std::vector<int> a(n);          // 能装 n 个整数
a.push_back(7);                 // 末尾追加一个 7
int len = a.size();             // 元素个数
std::cout << a[0];              // 和数组一样用下标访问
```

## 第 10 章　函数（一段有名字的代码）

### 10.1 定义

```cpp
返回类型 函数名(参数) {
    // 函数体
    return 值;    // 把"值"交回去
}
```

```cpp
int add(int x, int y) {    // 接收两个整数，返回它们的和
    return x + y;
}
```

### 10.2 调用

```cpp
int main() {
    int r = add(3, 4);     // r = 7
    std::cout << r << std::endl;
    return 0;
}
```

> 你现在天天写的 `main` 就是一个函数：`int` 是返回类型，`main` 是函数名。

## 第 11 章　struct（把多个数据打包成一个）

```cpp
struct Point {      // 定义一个叫 Point 的"复合类型"
    int x;
    int y;
};

int main() {
    Point p;        // 造一个 Point 盒子
    p.x = 3;        // 用 . 访问里面的成员
    p.y = 4;
    std::cout << p.x << " " << p.y << std::endl;   // 3 4
    return 0;
}
```
